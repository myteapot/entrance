# 1.2 Hierarchical State Machine Design

> Status: hot skeleton

## Confirmed

- Entrance needs a top-level hierarchical state machine design.
- The design must cover `NOTA / Arch / Dev / Agent` together rather than only one role in isolation.
- Simulation must gate upward handoff at every level.
- Local self-repair should happen before upward disturbance whenever the issue remains inside the same role boundary.
