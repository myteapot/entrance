# Entrance Project Workspace

This repository is formatted as a Microt workspace:

- [`entrance-src/`](./entrance-src/) contains the Rust workspace, Electron shell,
  SolidJS renderer, product README, and source-level agent instructions.
- [`entrance-wiki/current/`](./entrance-wiki/current/) contains the current
  project truth. Historical material lives under `entrance-wiki/archive/`.
- [`entrance-auto/`](./entrance-auto/) contains reusable validation and release
  workflows. Run-specific evidence and generated artifacts are ignored by Git.

For product usage and architecture, start with
[`entrance-src/README.md`](./entrance-src/README.md).
